# PasswordNotebook

一款轻量、本地优先的 Windows 密码管理器。基于 Rust 原生开发，无任何第三方运行时依赖，单文件免安装，双击即可运行。

## ✨ 主要功能

- **密码与账号管理**：支持记录标题、账号、密码、网址、分类、标签与备注。
- **快速检索与筛选**：支持多字段模糊搜索、分类与标签多维筛选及多种排序方式。
- **内置密码生成器**：支持自定义长度、字符规则，并可排除易混淆字符。
- **安全自动锁定**：
  - 支持锁屏（Win + L）或屏保激活时立即自动锁定。
  - 支持自定义空闲超时自动锁定。
- **剪贴板保护**：复制密码后按设定秒数自动清空剪贴板，防止隐私泄露。
- **便捷解锁**：支持本机安全免密解锁，可选配合 Windows Hello（指纹 / 人脸 / PIN）二次验证。
- **防误删回收站**：已删除条目进入回收站，支持随时还原，超期自动彻底清理。
- **安全恢复机制**：支持修改主密码，并提供专属恢复码以防遗忘。
- **轻量便携**：
  - 单个约 600 KB 的可执行文件（`pnb.exe`）。
  - 数据本地加密存储（默认保存在 exe 同目录下），不依赖网络，不上传云端。
  - 支持单实例运行，避免重复启动。

## 🛠️ 构建与运行

### 编译
```bash
./build.sh
```
编译产物位于 `target/x86_64-pc-windows-gnu/release/pnb.exe`。

### 运行
直接双击 `pnb.exe` 即可使用。首次打开将引导创建新密码库。
